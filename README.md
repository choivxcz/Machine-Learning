# Machine Learning Practice

## Description

This repository documents the study of machine learning in Python by Karl Sebastian V. Cuerdo. It contains lecture exercises, class activities, and notebooks, progressing from the fundamentals of NumPy and pandas to the first models built with scikit-learn.

## Notebooks

| Notebook | Topic |
|---|---|
| `ntbk0 - Python_Fundamentals.ipynb` | Python fundamentals |
| `ntbk1 - CrashCourse_NumPy_Pandas_Matplotlib_Seaborn.ipynb` | NumPy, pandas, Matplotlib, and Seaborn |
| `ntbk2 - Introduction_To_Machine_Learning.ipynb` | Introduction to machine learning |
| `ntbk3 - Nearest_Neighbor_Models.ipynb` | k-nearest neighbors models |
| `ntbk4 - Linear_Models.ipynb` | Linear models |

## Scripts

| Folder | Contents |
|---|---|
| `Numpy/` | NumPy lecture exercises and a knowledge test |
| `Pandas/` | pandas lecture exercises |
| `SciKitLearn/` | Introduction to scikit-learn, handling of missing data, ordinal and one-hot encoding, and k-nearest neighbors |
| `activities/` | Class activities |

## Datasets

The repository includes small datasets prepared for class exercises (for example `students.csv`, `barangay.csv`, and `sarisari_sales.csv`) and public datasets used in the notebooks: baseball Hall of Fame statistics (`500hits.csv`), medical insurance charges (`medical.csv`), and house prices (`train.csv`).

## Requirements

Python 3 with NumPy, pandas, Matplotlib, Seaborn, scikit-learn, and Jupyter.

```bash
pip install numpy pandas matplotlib seaborn scikit-learn jupyter
```

## Usage

Start Jupyter from the repository root and open any notebook:

```bash
jupyter notebook
```

The scripts can be run individually with `python <path-to-script>`.
