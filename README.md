# Machine Learning practice

My practice files from learning machine learning in Python: lecture follow-alongs, exercises, and notebooks, from NumPy and pandas basics to my first scikit-learn models.

## Notebooks

| Notebook | Topic |
|---|---|
| `ntbk0 - Python_Fundamentals.ipynb` | Python fundamentals |
| `ntbk1 - CrashCourse_NumPy_Pandas_Matplotlib_Seaborn.ipynb` | NumPy, pandas, Matplotlib, and Seaborn crash course |
| `ntbk2 - Introduction_To_Machine_Learning.ipynb` | Introduction to machine learning |
| `ntbk3 - Nearest_Neighbor_Models.ipynb` | k-nearest neighbors |
| `ntbk4 - Linear_Models.ipynb` | Linear models |

## Scripts

- `Numpy/`: NumPy lecture and knowledge check
- `Pandas/`: pandas lectures
- `SciKitLearn/`: scikit-learn basics, handling missing data, ordinal and one-hot encoding, and k-NN
- `activities/`: class activities

## Datasets

Small practice datasets made for class (`students.csv`, `barangay.csv`, `sarisari_sales.csv`, and others) plus public datasets used in the notebooks: baseball Hall of Fame stats (`500hits.csv`), medical insurance charges (`medical.csv`), and house prices (`train.csv`).

## Run it

```bash
pip install numpy pandas matplotlib seaborn scikit-learn jupyter
jupyter notebook
```
